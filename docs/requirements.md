# AETHER 2.0 需求规格与验收矩阵

## 需求解读

用户提供的手写稿将**五项顶层功能**列为「基础数据」「想定管理」「联合投送方案」「行动推演」「评估分析」，并提及地图图层、环境条件、关键基础设施状态、力量编组、可视化部署、甘特图、时间轴、气象条件、平台类型和结果统计。个别字迹的语义基于工程分析做了合理解释。

本项目应用于 **民用城市应急物流无人运载平台的离线教学模拟**，不存在真实车辆远程控制与安全关键用途。

## 验收矩阵

| 编号 | 要求 | 实现与验收 |
|---|---|---|
| R01 | 严格五个一级入口 | 首页五业务卡片，左侧恰好五个一级导航按钮，每个入口下有独立二级标签 |
| R02 | 真实中国城市地图 | 武汉、上海、成都、深圳可切换；经纬度示例地标；OSM 公共瓦片；断网时保留图网拓扑 |
| R03 | 基础设施管理 | 创建 / 编辑 / 停用设施，示例经纬度与健康度；禁止不合理城市坐标 |
| R04 | 通道管理 | 创建 / 编辑 / 受限 / 关闭通道；双向拓扑；禁止跨城连接 |
| R05 | 运力平台 | UGV / UAV 分类，载荷、速度、续航、可靠度、驻地与平台状态 CRUD（新增与参数维护） |
| R06 | 想定管理 | 城市隔离场景、新建及选中想定、天气/风速/能见度维护 |
| R07 | 任务配置 | 新增 / 编辑 / 删除任务，校验重量、截止时间、起点终点与所属城市 |
| R08 | 联合方案 | A* / Dijkstra、均衡 / 时效 / 风险三策略、分配结果、甘特图、历史快照与路线查询 |
| R09 | 行动推演 | 指定随机种子、指定 1–500 轮 Monte Carlo、事件记录、沙盘回放与历史运行选择 |
| R10 | 评估输出 | 成功率、准点率、时长、P90、利用率、综合评分、运行对比、JSON/CSV 报告 |
| R11 | 审计安全 | HMAC 令牌、PBKDF2 密码、RBAC 与管理员写操作审计；前端审计位于「基础数据」二级功能 |
| R12 | 部署质量 | Docker、FastAPI OpenAPI、SQLite 增量迁移、CI、Pytest、移动适配、交付文档 |

## 重要限制

- 地图底图来自真实 OpenStreetMap，但业务设施为 **近似 WGS84 演示位置**；边为**人工定义的合成图结构**，不是实际道路网。地图与模拟路线必须以不同图例表达。
- 目前 A*、Dijkstra 和 Monte Carlo 的调度并非严格全局最优算法，不是已验证安全控制系统。
- 单机同步仿真约束在小型实验；跨实例队列、用户并发、生产地理数据和大型业务压测待实施。
- Chromium 沙箱若被环境策略阻断，语法与 HTTP 测试仍可执行，但不等于完成真实浏览器视觉验收。
