# 需求规格与验收口径

## 源需求理解

图片中的关键词包括「无人投送/接运」「仿真实验」「基础数据」「规则/规定管理」「投送方案」「行动推演」「评估分析」「图层」「环境条件」「关键基础设施状态」「力量编组」「可视化部署」「甘特图」「时间轴/回放」「气象条件」「平台类型」「任务参数」和「结果统计」。部分字迹模糊，具体词条是工程化理解，而不是逐字保证。

本实现的业务域是**城市级无人物流平台协同配送的合成模拟**，不涉及真实无人机飞控、空域执照或现场调度。它旨在展示规划和推演流程的数据一致性，不等同于物理数字孪生系统。

## 质量与非功能性目标

- 可复现：同一方案输入快照与相同 seed 得到相同运行结果。
- 可靠性：网络不可达任务不会分配；已关闭路段从搜索中排除。
- 安全性：无令牌不能读取业务数据；viewer 不能修改规划、车辆或路网。
- 可移植：UI 不依赖商业 API/地图；Python 3.11+ 与常用 SQL 数据库。
- 性能边界：当前仿真为同步、单进程、单场景内计算；超过数百任务/多用户并行场景需引入任务队列和优化器。
- 正式投入使用前：数据库迁移、真实地理信息、抗并发写冲突、审计不可篡改、速率限制、身份体系对接、负载测试与安全审计均需进一步实施。
