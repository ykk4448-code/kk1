# AETHER 9.0 · 冰蓝业务工作台主题

## 本轮设计约束

- 一级首页只出现五个业务入口：基础数据、想定管理、联合投送方案、行动推演、评估分析；不能让颜色改版改变导航结构。
- 页面底色 `#f5f9ff`，白色主面板 `#ffffff`，浅蓝次层 `#edf5ff`，主操作蓝 `#246ab4`，正文深蓝 `#17334f`。
- 任务回放已选路线用蓝色 `#167bcb`；中断/不可用状态保留红色 `#c75962`，警戒风险可保留棕橙色。不能所有路线都涂红。
- 地图继续显示 OpenStreetMap 底图及版权署名，使用低饱和、轻提亮的瓦片处理；地理设施/路线是模拟数据，不能用于实际导航。
- 操作区保持浅蓝作为层次，而不是所有卡片都填满蓝色；统一输入、表格、顶部导航、时序条、平台检查器、结果曲线和播放器。
- 配色来自原创语义色板，不直接复制用户提供参考图的程序界面。

## 样式加载顺序

原有 CSS 不删除：`styles.css → workbench.css → mission-v6.css → design-v5.css → mission-v7.css → cartographic-v8.css → lightblue-v9.css`。最后一层可单独关闭，方便回滚。新主题使用明确的优先级覆盖旧色彩，但不重写业务模型。

## 质量保障

`pytest frontend/tests/test_lightblue_theme.py -q` 检查加载顺序、对比度、主要业务区域的主题覆盖和五入口存在性。原有后端/前端测试继续由 GitHub Actions 执行。

UI 预览是离线快照，写操作不可用；正式操作须启动 FastAPI 服务。浏览器联网时地图瓦片才可能显示；离线时仍显示地理网格和仿真节点。
