# AETHER 7 · 回放事件工作台

## 设计与功能边界

本次升级不改动一级门户的五个按钮，不重写已验证的运输方案及仿真算法。调整 `行动推演 → 推演控制` 和 `评估分析 → 综合评估` 共享的二级交互。继续用近似城市设施、合成路网和保存的首次迭代事件数据；这不是实时遥测和真实路线指挥平台。

## 操作改进

- **事件索引**：派遣、交付、风险扰动、任务中断；按发生分钟排序，可按事件类别、运输平台、任务描述或分钟搜索。每页增加显示 48 条，避免原来超过 100 条被截断。
- **播放时刻同步**：只读取 `#desk-slider` 的回放时间，时刻显示和事件“已发生/当前”状态每 300 ms 同步一次；不会启动第二个定时回放器，也不会为了刷新事件索引再请求遥测。
- **地图检查器**：点击“隐藏详情／查看平台详情”，可让地图获得更大的无遮挡区域；已有的地图点选平台与甘特图联动保持不变。
- **异常速查**：跳到第一条扰动或中断事件；无异常时切换为明确的空筛选状态。
- **体验与容错**：错误可以重试、空筛选有解释、输入框操作不被全局快捷键抢占、长文本不溢出、移动端事件列表单列。

## 浏览器测试与限制

- `frontend/tests/test_mission_v7_contract.py`：资源引用、脚本语义契约与 Node 事件排序/筛选单元测试。
- 本地 Playwright Chromium 离线 DOM 仿真执行了 12 个断言：105 条事件分页、搜索、筛选、异常跳转、自动播放时刻投影、详情开关、键盘定位、单次接口取数。
- 完整的后端服务浏览器联调、线上瓦片加载、压测、真实交通适用性**均不在本次验证范围内**。GitHub CI 负责验证整库接口回归和预览构建；CI 结果以远程运行状态为准。
