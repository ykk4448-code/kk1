# AETHER 6 · 行动推演工作台设计与交互

## 设计依据

按需求参考图的信息布局组织业务页面，**不复刻原图的地图内容或产品外观**：左侧独立的运力/任务甘特时序，中部城市底图及仿真轨迹，地图上的选中平台检查器，下方交付曲线与平台列表，最下方统一回放播放器与关键事件导航。

这是应急投送仿真，**非实时无人机指挥软件**。地理设施定位为演示位置，路网和扰动为合成数据。地图不能直接用于真实交通或飞行导航。

## 页面层级

- 一级首页仅保留五个业务入口（基础数据、想定管理、联合投送方案、行动推演、评估分析），**没有更改**一级导航。
- 二级 `#/simulation/control`：主任务时序、地图、平台详情、统计、事件索引和回放控制。
- 二级 `#/analytics/overview`：沿用共享评估工作台，布局和事件交互同步升级。
- 其他二级页面沿用现有功能和路由。

## 交互行为

1. 甘特图选择任务 → 选中平台、同一回放分钟、相应地图叠加；地图点击平台 → 左侧任务选中和右侧平台状态对应变化（现有 `assessment.js`）。
2. 时间轴播放器使用保存的首次仿真迭代事件，随拖动/播放获取该时刻的模拟速度、载荷、剩余里程和坐标；**不宣称是真实遥测**。
3. 新增时间快捷定位：开始、25%、50%、75%、结束，以及“首个异常”；所有按钮转发至已存在的 `#desk-slider`，不另设第二个时间状态源。
4. 新增事件索引：由 `/api/v1/simulations/{id}/assessment?minute=0.000` 的 `events` 数据生成；支持全部、异常、派遣、完成筛选。点击索引定位时间；不存在事件时明确空状态。
5. 键盘快捷键：空格播放/暂停，左右箭头逐事件，Home 回到开始，End 跳到结束。文本输入、选择框及模态框内不拦截键盘操作。
6. 原有 CSV 导出、方案切换、图层切换、全屏和多城市地图逻辑保留。

## 屏幕适配

- ≥ 1150px：左甘特，右大地图，平台详情作为可视区域内的浮动检查器。
- 830–1150px：甘特 + 地图，详情改为通栏信息区，避免遮挡地图。
- ≤ 830px：按地图 → 时序 → 平台详情的移动阅读顺序排列。
- ≤ 580px：KPI 变成两列，控制面板播放器变两行，全部按钮保持可点选。
