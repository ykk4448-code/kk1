# AETHER 10 | 工程工作台视觉规范

本版为工程设计系统（Engineering Operations UI）的设计落地，不更改核心业务路由、API 或仿真逻辑。

## 核心原则

1. **业务优先**：以信息层级、状态判读和稳定表格为中心，而非展示性渐变、发光图标、大片品牌底色。
2. **克制用色**：灰白作为大多数容器底色；工程蓝仅用于主操作、选中、可交互路径；青绿代表正常状态；橙色代表注意；红色仅代表失败和中断。
3. **统一规格**：卡片/控件圆角 3–5px，实线边框，默认无装饰性投影；正文 12–14px，关键指标 26–28px，等宽数字增强判读。
4. **真实数据语义**：仅展示“仿真工作环境 / 合成数据”，不用“真实在线遥测”文案；城市底图采用 OSM 原色，保留其归属标签，合成路径仍明确标注。
5. **页面结构稳定**：一级首页严格五个按钮：基础数据、想定管理、联合投送方案、行动推演、评估分析；进入后仅展示本模块二级功能。

## 工程实现

- `frontend/assets/engineering-v10.css` 最后加载，专门覆盖旧版演示风格；未来版本应通过 CSS 令牌和组件体系合并历史主题层，避免持续叠加。
- `frontend/index.html` 使用准确的仿真环境标识，移除误导性的在线设备标签。
- `scripts/build_preview.py` 将工程主题内嵌在离线预览中。离线预览只读，不能代表在线部署。
- `frontend/tests/test_engineering_theme.py` 校验 CSS 载入顺序、色彩对比度、地图不使用滤镜染色以及五入口不变。

## 验收范围

使用 Chromium 的隔离 HTML 演示页面验证一级首页及模块切换、桌面和手机视口溢出、前端执行错误。真实服务器 + 真实地图瓦片加载仍应在部署环境中做系统级验收。
