# AETHER 11 | 渐变海蓝工程工作台

本版将页面调整为任务工程工作台，沿用已有业务路由、接口和仿真计算。根据最终配色要求，以海军蓝渐变导航、舰艇灰背景与白色工作面为主，建立清楚的前景与背景层级。

## 界面组织

- 一级首页仍只有五个业务入口：基础数据、想定管理、联合投送方案、行动推演、评估分析。桌面以五段任务工作链排列；窄屏按原顺序纵向排列。
- 桌面二级功能集中在顶部横向功能带，取消左侧后台式菜单；窄屏显示可横向滚动的页内功能标签。每一页保留返回首页与城市选择。
- 指标合并为连续仪表带，统一等宽数字、单位和状态标识。
- 推演工作台突出任务时序、地图和平台详情；宽屏采用三栏，窄屏顺序堆叠。保留详情开关、事件定位、回放速度、全屏与导出。
- 组件采用 2–3px 圆角、细线框、清楚的中文标题与明确的操作层级；内容区最大宽度 2240px，避免超宽显示器上的表单和指标无限摊开。

## 字体与尺寸

采用本机已有字体，不依赖外部字体下载：中文模块名、导航、正文与地图标注统一使用本机 Noto Sans SC 现代中文黑体，缺失时回退到 Microsoft YaHei UI / Microsoft YaHei；关键指标使用正常宽度的 Segoe UI 数字；编号与时间使用 Consolas 等宽字。缺少指定字体时按 CSS 字体栈回退。

| 层级 | 桌面字号 | 说明 |
|---|---|---|
| 模块导航 | 17px，宽屏 19px | 黑体，选中项使用浅色底和深蓝文字 |
| 页面标题 | 34px，宽屏 36px | 黑体，统一标题基线 |
| 工作台标题 | 22px，宽屏 24px | 黑体，独立于业务说明 |
| 正文 / 表格 | 16px，宽屏表格 17px | 清晰中文字体与 1.65–1.75 行高 |
| 指标标签 | 15px | 辅助说明 14px |
| 关键指标 | 38px，宽屏 42px | Segoe UI，单位单独缩小 |
| 顶部功能带 | 高 108px，宽屏 116px | 独立上下文栏高 58px |

窄屏保留 15px 正文和 16px 功能标签；通过滚动标签、分行与内容重排适配，避免将全部字号缩小。任务列表行高不小于 80px，任务说明最多显示两行。

## 配送回放的任务聚焦

默认以选中任务为中心显示，取货点、交付点、物资、平台和当前阶段集中在地图上方。阶段来自已保存的首次迭代位置及终点事件：等待派遣 → 前往取货点 → 运送至终点 → 交付完成；原地取货、任务中断和缺少交付记录分别显示。

- 深蓝实线表示已行驶，蓝灰虚线表示待行驶，金褐虚线表示去取货；箭头说明路线方向。
- 当前任务只突出一个任务平台及其位置；其他平台在全局态势中查看，近距离重叠平台合并为数量标记，完整列表仍可逐台选择。
- 地图位置使用保存的位置事件插值，选中平台的 SVG 元素保持连接，播放时平滑移动；暂停和跳转立即定位，不另外启动动画时钟。
- 位置、阶段、路线进度和回放滑条共用同一时间。重复经过同一节点按事件先后区分；缺少交付证据不能显示 100% 交付。
- 路线为合成通道示意，不表示沿城市实际道路的导航轨迹；地图中保留此标识及 OSM 署名。

新增 `mission-view.js` 为纯展示状态计算，未修改后台调度、仿真结果或现有数据库。离线预览会同时内嵌该模块。

## 文件与验证

终端主题继续使用 `frontend/assets/engineering-v10.css`，直接更新原文件，未追加新的主题加载层。`scripts/build_preview.py` 会自动内嵌此样式；本地服务刷新页面即生效。

- `frontend/tests/test_engineering_theme.py`：加载顺序、关键文字对比度、五入口与仿真语义。
- `frontend/tests/test_mission_console_contract.py` 和 `test_mission_v7_contract.py`：保留任务台、事件与回放交互约束。
- 浏览器检查：桌面与窄屏五模块导航、页面横向溢出、全屏地图、详情开关和回放进度。

`frontend/tests/test_mission_route_state.py` 验证空驶取货、往返经过同一节点、交付、中断、缺少记录与历史相对坐标。
