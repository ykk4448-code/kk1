# 中国城市地图和数据来源 / 地理约束

- 地图底图：OpenStreetMap 标准瓦片（在线；客户端在视口内请求），© OpenStreetMap contributors，版权与使用政策见 https://www.openstreetmap.org/copyright 与 https://operations.osmfoundation.org/policies/tiles/ 。
- 地理坐标：`backend/app/cities.py` 内人工整理的近似 WGS84 地标位置；为演示与教学用途，不是实测站台/仓库入口，未与真实道路节点做坐标匹配。
- 路网连线：`LINKS` 中定义的**合成图结构**，以地标之间的大圆距离乘演示系数构造成本；不能当做真实公路或空域航线。
- 多城隔离：场景拥有 `city_id`，节点拥有 `city_id`，创建任务与通道时校验城市；规划前再次过滤所属城市网络，历史快照独立。
- 动画位置：回放为按模拟事件与合成节点显示的离散位置记录，不具备精确轨迹和实时定位能力。
- 地图加载：瓦片网络请求失败时仍显示地理坐标系、规划线与节点，必要时配置本地瓦片托管；不能大规模直接抓取 OSM 公共瓦片。
- 新设施坐标：需提供经纬度（地理坐标要求落在示例城市中心约 1.6° 范围内），便于在相应城市地图呈现。

如需生产道路路由，应该与具有许可的道路图提供方集成并明确地图坐标系/导航精度/动态路况，重新验证通道成本模型；此 demo 不包含该能力。
