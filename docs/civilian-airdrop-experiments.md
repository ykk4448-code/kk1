# 民用应急空投实验平台：模型、实验记录与验证

## 产品边界

AETHER 5.0 的活动工作区是一个**纯合成的民用应急物资空投教学模型**。它用于比较简化假设下的任务分配、方案规划和多轮随机扰动结果；不是飞行控制系统、真实航线规划器、气象决策工具或飞行安全认证系统。

- 当前活动网络：`civil-airdrop`，默认想定：`SCN-CIVIL-AIRDROP`。
- 场景只包含大陆侧合成补给点、台湾侧合成接收点，以及两侧之间的直接空投示意连线。
- 所有节点的经纬度都是相同的固定占位值 `(120, 30)`。地图强制使用相对 XY 图，不显示真实地理底图或坐标归属。
- 数据库字段 `distance_km` 为兼容历史 API 而保留；在此活动网络中它表示**抽象模型距离单位**，不是公里或真实航程。
- 物资重量使用 kg，任务截止时长使用分钟。无人机速度、续航、可靠度及环境系数均为合成输入。
- 旧网络和旧仿真记录会保留用于审计/回放，但活动列表不展示它们；旧网络的新增、编辑和新仿真操作被拒绝。

## 预置合成场景

首次初始化时，系统建立 6 个合成节点、6 条直接空投示意通道、6 台民用应急无人机、6 项物资任务，并生成一条基线方案、一个 80 轮仿真运行和一条基线实验记录。初始化可重复执行；它不会把用户新建的 `civil-airdrop` 想定归档。

基线实验使用固定随机种子 `20261020`，轮数为 80。它用于确认软件链路可运行，不是经过真实数据校准的性能基准。

## 环境变量与计算口径

实验参数由 `backend/app/schemas.py` 校验，粗粒度模型因子集中在 `backend/app/airdrop.py`。当前参数包括：

| 参数 | 允许值 / 范围 | 模型用途 |
| --- | --- | --- |
| 天气 | 晴朗、降雨、有风、低能见度 | 影响规划代价与扰动强度 |
| 风速 | 0–60 km/h（模型输入） | 影响持续时间、风险、续航因子与随机扰动 |
| 降雨 | 无、小雨、中雨 | 影响持续时间、风险、续航和扰动因子 |
| 云底情景 | 高、中、低 | 推导合成能见度，并影响模型因子 |
| 海况情景 | 平稳、中等、较大涌浪 | 影响跨海示意任务的粗粒度因子 |
| 载荷类型 | 轻载、标准、医疗物资 | 影响持续时间、风险与续航假设 |
| 飞行剖面 | 保守、标准、较高 | 影响持续时间、风险与续航假设 |
| 电量预留 | 20%、30%、40% | 减少可用于任务的模型续航 |
| 随机种子 | 0–2,147,483,647 | 固定伪随机数序列以支持复现 |
| 迭代轮数 | 1–500 | 多轮随机扰动统计 |

模型会把归一化输入、推导出的能见度、`model_factors`、模型版本和免责声明保存进参数快照。相同代码版本、输入快照、随机种子和轮数应产生相同的仿真事件、样本与指标。

这些因子是可解释的教学假设，不是由实际飞行数据拟合或验证的概率模型。不同环境变量的结果只能作为**模型内部对照**，不得外推为真实无人机可飞、可达、可按时交付或安全的结论。

## 推荐实验流程

1. 进入“应急场景”，检查任务、物资重量、截止时长和无人机编组。
2. 在“空投方案”生成方案。规划会把场景天气、风速和能见度映射为默认实验参数，并将参数快照保存到方案。
3. 进入“空投仿真 → 实验记录”，设置环境变量、规划策略、算法、随机种子和迭代轮数，选择“运行并保存实验记录”。
4. 查看实验列表中的成功率、准点率、评分、参数摘要和模型版本；通过“打开回放”检查关联仿真，或导出 JSON 留档。
5. 进行对照时，一次只改变一个或一组预先声明的变量，保持其余变量、随机种子和迭代轮数一致，并在备注中记录研究问题和观察结果。

“保存预设”只将变量写入当前浏览器本地存储；“运行并记录”才会向后端提交仿真并生成服务器端实验记录。

## 实验记录的数据结构

每条 `experiment_records` 记录关联一个想定、方案和仿真运行：

- `id`：实验记录编号。
- `scenario_id`、`plan_id`、`run_id`：可追溯的关联 ID。
- `parameters`：归一化参数、派生模型因子、模型版本和免责声明。
- `results`：指标、方案摘要、随机种子、迭代轮数、样本数及关联 ID。
- `model_version`：模型版本标识（当前为 `civil-airdrop-sim-v1`）。
- `created_by`、`created_at`：创建者与创建时间。

实验输入和结果不允许通过 PATCH 修改。实验名称和备注可补充，用于记录复核结论；这不会覆盖已保存的参数快照、方案、运行事件或指标。

## API 快速示例

所有接口位于 `/api/v1`，需要登录。演示环境默认创建 `admin` 演示用户；部署到真实环境时必须关闭演示模式并配置安全的认证和密钥。

- `GET /scenarios`：列出活动想定。
- `GET /network`：获取活动空投网络。
- `POST /plans`：按想定参数生成方案。
- `POST /simulations`：运行已保存方案的多轮仿真。
- `POST /experiments`：生成方案、运行仿真并保存实验记录。
- `GET /experiments?scenario_id=SCN-CIVIL-AIRDROP&limit=100`：列出实验记录。
- `GET /experiments/{experiment_id}`：读取完整记录。
- `PATCH /experiments/{experiment_id}`：仅更新名称或备注。

创建实验的请求示例：

```json
{
  "scenario_id": "SCN-CIVIL-AIRDROP",
  "name": "晴朗基线重复试验",
  "notes": "固定种子和轮数，用于复现基线。",
  "strategy": "balanced",
  "algorithm": "astar",
  "seed": 714,
  "iterations": 80,
  "parameters": {
    "weather": "clear",
    "wind_kmh": 8,
    "rain": "none",
    "cloud_base": "high",
    "sea_state": "calm",
    "payload_profile": "standard",
    "altitude_profile": "standard",
    "battery_reserve_pct": 30
  }
}
```

## 本地启动与验证

在仓库根目录运行：

```bash
pip install -r backend/requirements-dev.txt
PYTHONPATH=backend uvicorn app.main:app --app-dir backend --reload
```

在另一个终端执行回归测试：

```bash
PYTHONPATH=backend pytest backend/tests -q
node --check frontend/assets/app.js
node --check frontend/assets/assessment.js
node --check frontend/assets/map.js
python scripts/build_preview.py
```

`preview.html` 是离线只读预览；新建想定、运行仿真和写入实验记录需要启动正式本地 API 服务。
