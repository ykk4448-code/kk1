# AETHER 8.0 · 海图式沙盘主题

这一版本是对用户参考图的配色回应：在保持既有五入口一级首页及二级功能不变的前提下，统一浅海蓝、卡其米黄、暖白、石墨灰、红色选中路径的视觉语义。并非复制参考图的软件资产或地图。

| 角色 | 色值 | 用途 |
|---|---|---|
| 纸面背景 | `#f7f4e9` | 业务布局背景 |
| 暖白面板 | `#fffef9` | 表格与详情 |
| 卡其色 | `#ded7b3` | 沙盘与摘要区域 |
| 海水蓝 | `#b9d5d5` | 地图色调 |
| 深海蓝 | `#2a4d60` | 播放器和文字 |
| 工业青 | `#277a82` | 常规状态和曲线 |
| 路线红 | `#b9433e` | 高亮任务路线和重点提示 |
| 警示赭 | `#bd8639` | 次级警示 |

地图继续请求 OpenStreetMap Raster 瓦片并展示版权归属。色彩过滤仅改变浏览器视觉表现，不伪造海岸线或真实导航地图；网络不可用时底图可能不可见，设施和合成路网仍可展示。任务路径、示例设施、速度、载荷和风险均为仿真数据，不能用作现实导航、安全关键调度或无人装备控制。

实现为 `frontend/assets/cartographic-v8.css`，依序在旧样式后加载，故可通过去掉该引用恢复原有主题。有关视觉样本应标注为“静态样式样本”，不能宣称进行了完整的服务端浏览器验收。CI 执行主题入口与颜色对比度检查。
