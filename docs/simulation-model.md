# AETHER 2.0 联合投送合成仿真模型

## 1. GIS 与图结构

提供武汉、上海、成都、深圳 4 个城市，每个城市独立维护节点（近似地理经纬度 WGS84）、双向仿真通道、运力、场景和任务。前端地图使用 Web Mercator 视窗和 OpenStreetMap 公开底图瓦片，节点投影显示在真实地理参考框架下。

**切勿混淆**：地图底图可代表真实街区，但规划路径是连接示例地标的合成边，并没有匹配真实道路、路况、航线或路网数据。仿真边长度为两端地理大圆距离乘合成因子，不构成实际可行路线长度。

## 2. 路径求解

`G=(V,E)` 为独立城市双向加权图。失效设施与封闭路段不能入图。边的策略代价为

`C(e) = distance_km(e) * weather_multiplier * restriction_multiplier * (1 + risk(e) * strategy_weight)`。

晴/雨/风/雾天气系数为 `1.0 / 1.18 / 1.28 / 1.22`，受限路段系数为 `1.45`，时效/均衡/风险策略权重为 `0 / 3 / 9`。注意风险因子为合成模型的无量纲参数，并非实际交通事故统计。

Dijkstra 使用 0 启发式，A* 使用可行图边长和相对坐标的保守比率推得的欧氏距离启发式，保证搜索下界；同一数据快照可做路线对照。UI 提供两地标即时路径查询。

## 3. 联合运力编排

按任务优先级、时限与编码排序，依次对可用平台检验载荷、可达性、单程模型续航、时限和示例天气限制。对每台平台计算再定位线路 + 交付线路，按策略选择最优可行候选并更新空闲时间，输出任务甘特图与不可行任务原因。

该模型为**可解释的贪心调度**，不构成大规模车辆路径问题的全局最优解；没有正式无人机空域建模、地面交通动态流量或多段补能设施。

## 4. 行动推演

固定种子的 Monte Carlo 仿真：

`P(incident) = min(0.55, edge_risk * weather_stress * (1.25 - 0.35 * reliability))`

触发事件时模拟额外延迟 3–13 分钟，少量概率中断任务；任务同时施加独立均匀随机工况扰动，同一平台前序延迟传递至后序任务。每轮记录成功率、准点率、总时长、延迟、扰动与综合分，仅首轮保存位置和事件时间线以降低存储占用。

总分（100 分）：`48 * 成功任务比例 + 35 * 准点比例 + 17 * max(0,1 - 事件数/(4*分配任务数))`。

## 5. 数据一致性与边界

每份规划记录包含场景环境、节点、边、运力的**输入快照**。运行时从快照加载，不因后续数据库变更而改变；相同计划和 seed 的复现测试应一致。

所有位置、风险、天气扰动概率均为教育演示级合成样本；不能用于真实车辆导航、无人机飞行、交通安全或设施生命安全评估。
