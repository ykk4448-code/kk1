# 联动评估工作台

## 使用流程

1. 在想定管理中配置任务、环境和参演平台。
2. 在联合投送方案中生成规划结果。
3. 在行动推演中展开“新建多轮推演”，选择方案、种子和轮次后运行。
4. 在评估分析的综合评估页选择运行记录，点击任务、平台或地图标记查看详情。
5. 拖动回放时间、点击结果曲线或使用逐事件按钮定位；需要同屏分析时使用全屏按钮。Escape 退出全屏。
6. 导出 CSV 核对任务级结果；完整归档和多轮样本仍可在报告中心导出。

## 布局与交互

参考任务时序、态势地图和结果统计的联动布局，提供左侧任务时序、中央空间态势、右侧平台详情、下方结果曲线和统一播放控制。宽屏并列，窄屏按阅读顺序排列；390px 与 1440px 视口均进行了浏览器验收。

选中的任务展开派遣、运输航段和交付阶段。航段时间直接使用持久化位置事件，不生成没有模型证据的装载或返航阶段。计划时段使用虚线，首次迭代实际时段使用实线，扰动事件单独标记。

图层开关只影响当前观察，不修改方案快照。城市底图使用 OSM；底图无法联网时仍可查看设施和规划通道。地图文字使用碰撞避让，完整设施名可由节点标题或点击查看。

## 指标口径

| 指标 | 口径 |
| --- | --- |
| 当前任务完成率 | 回放时刻前首次迭代成功交付数 / 全部任务数；包括未分配任务 |
| 已结束任务成功率（曲线左轴） | 成功交付数 /（成功交付数 + 中断数）；尚未结束任何任务时不显示成功率 |
| 累计交付、中断（曲线右轴） | 首次迭代到达或中断事件的累计数量 |
| 多轮平均成功率、准点率、综合评分 | 原仿真引擎对所有随机迭代的汇总，不随回放时间改变 |
| 当前速度、载荷、剩余航程 | 基于方案、任务和首次迭代事件推算，不是真实传感器数据 |
| CSV 结果 | 当前运行全部已分配与未分配任务；包含计划/实际时间、截止时间、结果和未分配原因 |

CSV 使用 UTF-8 BOM，转义引号和换行，保护可能被电子表格解释为公式的文本。导出的实际结果属于首次迭代；不能代表每一轮随机实验均得到相同结果。

## 历史数据兼容

历史方案可能只有 XY 相对坐标，没有经纬度或任务重量。回放保留原快照，缺少经纬度时使用明确标注的相对坐标；迁移生成的同一占位经纬度也不作为有效地理定位。未知载荷显示“—”，未知交付重量不计成 0。完成或中断后，速度与载荷清零。

原数据库不自动替换为新版四城市样例。旧数据保持原样，新建方案、任务与推演正常使用当前配置。修改前的数据库备份保存在交付目录的 `kk1-runtime/backups/`。

## 验证

- 后端覆盖原有业务测试及旧快照、占位坐标、未知重量、回放清零、任务阶段、事件统计、权限和空方案等回归测试。
- 浏览器在独立数据库中验证了创建想定、添加任务、生成方案、运行 20 轮推演、评估终点和实际 CSV 下载。
- 搜索、按平台筛选、图层开关、缩放、自动播放到结束、移动与桌面布局经过实际操作验证。

所有数据和路线仍属于民用应急物流教学仿真，不用于真实车辆导航、飞行控制或实际调度。
