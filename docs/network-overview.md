## 使用

打开「评估分析 → 综合评估」，在想定下拉框选择「多枢纽协同投送」。旧想定内提供切换入口。首次使用默认选择完整演示；已有会话保持原选项。

入口 HTML 禁用缓存，并按全部静态资源内容生成版本目录。相对 ES 模块导入也随版本变更，防止新 HTML 继续执行缓存中的旧地图或回放脚本。原始 `/assets` 地址继续提供兼容访问；离线预览保留全部最新模块。
