# 联合投送仿真平台

平台名称统一使用“联合投送仿真平台”。首页保留原有左侧五个入口与中国地图的排版，不增加概览卡片布局。

| 一级模块 | 主要功能 | 对应页面 |
| --- | --- | --- |
| 基础数据 | 基础设施、投送通道、实体基本信息、操作审计 | `#/data/nodes`、`edges`、`vehicles`、`audit` |
| 想定管理 | 当前想定和基本信息、投送任务、力量编组、可视化部署、环境条件设置、关键基础设施状态 | `#/scenario/list`、`tasks`、`formations`、`deployment`、`conditions`、`facilities` |
| 联合投送方案 | 方案编排、路线分析、方案档案 | `#/planning/workspace`、`route`、`archive` |
| 行动推演 | 推演控制、运行状态、事件日志、历史运行、实验记录 | `#/simulation/control`、`telemetry`、`events`、`history`、`experiments` |
| 评估分析 | 综合评估、运输投送统计、投送结果统计、效能指标、方案对比、评估报告 | `#/analytics/overview`、`transport`、`delivery`、`metrics`、`compare`、`reports` |

力量编组提供实体基本信息入口；可视化部署包含可保存的图层控制。环境条件和基础设施状态继续使用既有保存接口。

行动推演的平台详情显示位置、当前速度、当前载重、装载物资、剩余燃料 / 电量及剩余模型续航。当前无人机为电动平台，电量百分比按模型续航比例折算，不伪造燃料升数。事件日志可定位到同一回放时刻，原有 0.5 倍默认慢速动画保留。

模块标签集中在 `frontend/assets/navigation.js`，原有路由标识、网络标识及历史实验快照保持兼容。已保存历史内容使用原始记录，界面去除旧品牌措辞；不会为更改名称重建实验或改变计算结果。
